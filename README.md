# SPI-AXI4-Lite-Bridge-VHDL
VHDL implementation and ModelSim simulation of an SPI-to-AXI4-Lite bridge.


## Overview
This project implements an SPI-to-AXI4-Lite bridge using VHDL. It receives commands, addresses, and data through the SPI interface and generates corresponding AXI-like control signals for read and write operations.

The design uses a Finite State Machine (FSM) to control the transaction flow and an internal memory model to demonstrate the read and write functionality.

## Features
- SPI command decoding for read and write operations.
- FSM-based transaction control.
- Serial reception of command, address, and data.
- Generation of AXI-like address, data, and valid signals.
- Internal memory model for simulation.
- Testbench-based functional verification using ModelSim.
- Waveform analysis to observe signal behavior.

## Tools and Technologies
- **Hardware Description Language:** VHDL
- **Simulation Tool:** ModelSim
- **Communication Protocol:** SPI
- **Bus Interface Concept:** AXI4-Lite
- **Design Concepts:** FSM, RTL Design, Functional Simulation

## Project Structure
- `spi_axi_bridge.vhd` — Main VHDL design.
- `tb_spi_axi_bridge.vhd` — Testbench for simulating SPI transactions.
- `simulation_waveform.png` — Simulation output waveform.

## Simulation Output
The ModelSim waveform illustrates SPI command, address, and data transfers, along with the corresponding control signals generated by the bridge.

The testbench is used to verify the design's behavior during simulated read and write transactions.

![ModelSim Simulation Waveform](simulation_waveform.png)

## Design Limitations
This project is a simplified simulation model intended to demonstrate SPI transaction decoding and AXI-like signal generation. It uses an internal memory model and does not implement all the handshake and response channels required for a fully AXI4-Lite-compliant interface.

## Learning Outcomes
- Understanding SPI serial communication.
- Implementing FSM-based control logic in VHDL.
- Exploring memory read and write operations.
- Writing testbenches and analyzing simulation waveforms in ModelSim.
